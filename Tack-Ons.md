# The Tac-Ons Feature

The Tac-Ons feature is meant to be the Eagle Bot equivilant of Chrome Extenstions, or Minecraft Data-Packs. It's not only a way for acaedemies to make their specifc versions of Eagle Bot more personalized, but also to allow up and coming learners at Actons all over the world to build and ship products in a sort of inccubator. 

### The Genral Flow

Every admin will have acess to a Tac-Ons market. The tac-ons market will have a grid of lcickable tiles for each tac-on, which upon being clicked will open to a details page about that tac-on, where the admin can then choose to download it and such things as descriptions, number of downloads etc. 

Once the tac-on is downloaded, the exact code detailed in that tac-on will fire up, and add whatever it is the idea was to add to Eagle Bot. 

This means the creation of a mini porgramming language that allows for the user to, in essence, tell the app what to add and how to add it. The general thing these things should allow are live interaction with all the base features, and other tac-ons. You need to think about how it is you can best implement this. Be creative, and think on what similar systems like Chrome Webstore let Extenstions do.

### How This Will Work For Aspiring Developers

Admins at different academies can allow specifc learners to hold "Dev" status, for one thing, give them acess to the dev menu where they can upload Tac-Ons, push updates, selct visbility on their Tac-Ons, see a lot of differnt statistics and more. The "dev" status also allows for the creation of that learners Global profile, where such details as bio, home academy, NGA and Tac-Ons can be displayed.

### Future Steps

In the future, it may be possible to monotize Tac-Ons (allow for developers to charge for them).

### Dev Portal

Create a dev page for Eagle Bot, accessed through using the shortcut Ctrl+D on the keyboard, which will take you to a login page. If you have been inivted by the head dev in the past, you can use your login credentials to acess the dev protal, where devs can send out notices, and uplaod offical Tac-Ons.
