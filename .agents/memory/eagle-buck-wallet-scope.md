---
name: Eagle Buck wallet scope
description: Why Eagle Buck Market requires one shared academy wallet rather than separate studio wallets.
---

Eagle Buck Market must keep one wallet for each learner across studio views.
Use an academy-wide installation, not separate studio installations.

**Why:** The user requires 100 points per Eagle Buck and no learner holding more
than 10 Eagle Bucks. Multiple studio/academy wallets could bypass that limit.
Keeping a single shared installation preserves ordinary Tac-On install and
academy isolation rather than joining financial records across unrelated installs.

**How to apply:** Keep the Eagle Buck package academy-wide when extending its
pages or position desks. Do not introduce a second wallet just to support another
studio view. Earnings are self-reported with a source/reason; the user did not
request an approval workflow.

The current Shopkeeper should be able to add items to the market and add points
to their own learner wallet.

**Why:** The user explicitly requested both capabilities; the Shopkeeper is not
limited to reviewing purchase logs.

**How to apply:** Expose catalog management on the market and Shopkeeper desk
only to admins/current holders. Retain self-reporting with a source/reason and
the shared 1,000-point wallet cap. Expired holders lose catalog privileges.
