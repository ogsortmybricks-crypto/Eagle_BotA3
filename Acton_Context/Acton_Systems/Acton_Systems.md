# Common Acton Systems

This document contains a list of a few of the most common systems used at Acton Academies. All other files used to describe Acton Systems are available in the Acton_Systems folder.

- Hero (or Eagle) Bucks:
A description of the fucntionality of this system is available by the name of Hero_Bucks.md

- Accountibilty Partners (aka Running Partners):
A system essetnaially composed on the idea of a pair of heros being partnered with the mission of holding one another accoutable. The exact nature of the responsibilites of these partners are largely specifc to the academy.
